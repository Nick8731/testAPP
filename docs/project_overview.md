# Project Overview

## 專案名稱
SmashCoach

## 目標
讓使用者可以學習羽球技術、上傳自己的羽球影片、取得 AI 動作評分與修正建議，並長期記錄是否進步。

## 目前技術清單
- 高遠球 / Clear
- 殺球 / Smash
- 平球 / Drive
- 挑球 / Lift
- 切球 / Slice
- 吊球 / Drop Shot
- 放網 / Net Shot
- 接殺 / Smash Defence
- 啟動步 / Split Step

## 目前已完成
- Flutter App 基本架構
- 技術分類
- 教學影片
- 技能詳情
- 學習進度
- AI Coach
- 影片選擇
- Pose Detection
- 單張 / 區間分析
- 骨架預覽
- 關節角度
- 第一版規則式技術評分

## 下一階段
會員、REST API、SQL Server、分析歷史、進步比較。
