# SmashCoach 完整度盤點

## 已可操作流程

- 技術分類、文字教學、學習進度與課程完成狀態
- 高遠球、殺球、挑球影片播放；缺片課程會明確標示為文字教學
- AI 影片選擇、區間分析、姿勢骨架、規則式評分與結果儲存
- 註冊後回登入、JWT 登入、帳號資料、私人分析紀錄與刪除
- 依技術篩選分析歷史與查看進步趨勢
- 單打／雙打戰術與動畫站位
- 高遠球／殺球肌肉、動力鏈、影片階段同步與人體肌群示意
- 使用指南、拍攝建議、分數限制與資料處理說明

## 本次體驗補強

- API 連線逾時、拒絕連線及伺服器錯誤改為一般使用者可理解的訊息
- 登入／登出狀態跨頁即時同步，暫時斷線不會直接清除登入狀態
- 註冊增加確認密碼，並清楚說明建立帳號後必須登入
- 同一次 AI 分析成功儲存後停用按鈕，避免重複紀錄
- 移除不存在的影片路徑與不相符的殺球替代影片
- Android 顯示名稱改為 SmashCoach

## 尚需外部素材或正式環境

1. `clear.mp4` 與 `smash.mp4` 現為相同檔案；須提供獨立標準影片並重新校正。
2. 平球、切球、吊球、放網、接殺、啟動步尚缺相符示範影片。
3. 第一版 AI 是規則式姿勢分析，需教練標註資料才能進一步驗證準確度。
4. 正式發佈前需把 API 與 SQL Server 部署至 HTTPS 環境，完成隱私政策、備份與監控。
5. 建議以不同身高、慣用手、服裝、光線與拍攝角度進行真機測試。
