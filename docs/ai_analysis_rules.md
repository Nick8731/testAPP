# AI Analysis Rules

## 重要
目前是第一版規則式分析，角度門檻主要用於原型驗證，不可視為正式運動生物力學標準。

後續需加入：標準影片、教練校正、動作階段、相機角度標準化、關鍵影格、速度與身體旋轉。

## 共用角度
- 手肘：Shoulder → Elbow → Wrist
- 肩膀：Hip → Shoulder → Elbow
- 膝蓋：Hip → Knee → Ankle

## 技術評分項目

### 高遠球
架拍、手臂伸展、肩膀上舉、膝蓋穩定、引拍完整度

### 殺球
架拍、手臂伸展、肩膀上舉、擊球高度、下肢穩定、引拍完整度

### 平球
手肘位置、擊球高度、手臂控制、身體穩定、回拍準備

### 挑球
膝蓋下沉、手臂伸展、擊球手位置、重心穩定、隨揮

### 切球
架拍、手臂伸展、肩膀位置、擊球點、隨揮控制

### 吊球
架拍、手臂控制、擊球高度、身體穩定、隨揮控制

### 放網
重心降低、手臂伸展、擊球手位置、膝蓋彎曲、身體穩定

### 接殺
重心、膝蓋彎曲、手肘位置、擊球手位置、防守準備

### 啟動步
膝蓋彎曲、重心高度、腳步穩定、身體平衡、啟動準備

## 精準化方向
```text
影片
→ 動作開始
→ 架拍
→ 引拍最大點
→ 擊球附近
→ 隨揮
→ 各階段獨立評分
→ 合成總分
```
