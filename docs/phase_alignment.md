# 固定取樣與人工階段對齊 v3

## 實際改動

- 抽圖先以影片第一個影格為零點，建立 10 fps 固定格，再選使用者標記的格；不使用區間起點作抽樣相位，也不再從區間挑最高分。
- 播放／拖曳到要比較的姿勢，選「準備／引拍」「揮拍／出手附近」「隨揮／回位」，按「暫停並標記這個階段」，再分析。
- 階段是人工確認，不是自動辨認擊球；三種名稱只提供可比對的標記，不改變既有技術評分權重，不宣稱完成各階段生物力學評分。
- 區間只確認標記落在合法範圍內。標記不在區間時要求重選，不偷偷換影格或夾到邊界。分析中的標記／持拍側／區間不可改動。
- 單張分析也使用影片零點 0.1 秒固定格，但仍標示為單張，不假稱已人工對齊階段。
- 高遠球膝蓋分項保留原型 125–165° 區間和原權重，區間外 5° 由 90 分線性漸降至 70 分；避免 124.9／125.1 或 164.9／165.1 附近突然跳 20 分。這是工程平滑，不是認證動作標準。其他分項門檻與其他八項技術評分尚未改動。
- 版本為 `pose-phase-v3`；保存持拍側、人工阶段名稱、固定時間格與範圍。舊資料不追溯重算。

## 取樣基準造成差異的原因

舊方式按各自區間起點每 0.5 秒取樣，區間起點稍有不同，就可能選到不同的最高分影格；角度接近階梯門檻時，分項與總分也可能不同。新方式在兩個合法範圍使用同一標記時間，對齊同一個影片零點固定時間格，並使用相同抽圖濾鏡。公開文件只說明工程原因，不保留個人分數與原始分析區間。

這不表示舊分數會自動變相同，沒有修改已儲存的紀錄。若重新標記的是不同時間格、不同原片或不同動作階段，仍可能得到不同分數。

## 取樣與限制

[FFmpeg fps 濾鏡說明](https://ffmpeg.org/ffmpeg-filters.html#fps-1)：固定輸出頻率透過丟棄或重複來源影格實現，不是生成新中間動作。APP 先重設來源時間，再 fps、select；為保持固定基準，不做區間相對 input seek。

標記時間是固定格時間，不保證是來源影片實際觸球時間或原始 PTS；0.1 秒精度不是逐原片 frame 精度。仍受骨架偵測、影片畫質與鏡位影響。不能保證不同裝置或拍攝相同動作會同分。此版本為人工階段姿勢比較，不是完整動作序列評分。

為避免解碼全片，選定格後只輸出一張；仍需要解碼至目標時間，長影片較後方的標記可能耗時。沒有量測所有裝置性能。原骨架模型、帳號/API及課程不重寫；分析紀錄保留。

## 驗證

- 區間起點變動不移動同一標記；邊界外、無效時間不自動替代。
- 膝蓋兩側門檻連續性與每 0.1° 的分數差驗證。
- 人工標記控制與忙碌鎖定測試。
- 九項相同骨架重複評分與既有課程／會員測試保留。
- Android 原生診斷使用本機參考影片，在不同合法區間標記同一固定時間格；兩次抽圖逐位元組一致，兩次 ML Kit 高精度模式偵測及規則式評分一致。這不是實際會員原始上傳檔的重跑證明，也不是跨裝置保證。診斷未新增會員分析紀錄；參考影片不包含在公開分享副本中。
- 修正歷史頁刷新回呼可能回傳 Future 的問題，增加篩選刷新測試。
- Flutter 完整 77 項測試及後端隔離 4 項測試通過，靜態檢查無問題；另外有中文標記畫面的渲染檢查。兩份臨時測試影片副本已移除，專案原片保留。

自動動作分段與教練標註校正仍需原影片及標準資料，本次未假稱已完成。
