# 動漫課程圖片提示詞

模式：imagegen 技能的內建圖片生成／編輯工具。透明背景由生成工具提供；未使用 Runway、CLI 圖片 API 或其他影片服務。

角色參考：使用者先前核可的角色；短深棕髮、黑色紫藍運動上衣、深藍短褲、白色球鞋。所有圖以右手持拍示範。

成品位於 assets/images/lessons/（45 張）及原有 assets/images/drive/（4 張），每張 512×512 RGBA。

圖集切分只抽取本格角色、保留原透明邊緣、等比例縮放及留白；不重繪姿勢、不修造手部或球拍。發現圖集矩形裁切帶入鄰格鞋子後，改為按獨立角色抽取，已重新渲染檢查。
